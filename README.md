# YC-or-not-YC

This is a web app for finding out whether your idea would have qualified for a [YC](https://ycombinator.com) batch or not. 
I have no idea how the investor brain works, I don't always understand why some companies get funded and some don't. 
This app compares the user's idea with companies selected in a particular YC batch. I used [Jev](https://typesafe.ai) for the comparison.
